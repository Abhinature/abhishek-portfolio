# Abhishek Kumar Choudhary — React Portfolio

A custom responsive portfolio built with React + Vite, with a dark editorial design, lime accents, your supplied portrait, project cards, skills, career approach, and contact links.

## Run on your computer
1. Install Node.js (LTS).
2. Extract this ZIP and open the project folder in a terminal.
3. Run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown by Vite.

## Publish for free (recommended: Netlify)
### Option A — GitHub + Netlify
1. Create a GitHub account if needed, then create a **public** repository such as `abhishek-portfolio`.
2. Upload all project files and folders from this ZIP (do not upload only the ZIP itself).
3. Go to https://app.netlify.com/ and sign in.
4. Choose **Add new site → Import an existing project**, connect GitHub, and choose the repository.
5. Build command: `npm run build`
6. Publish directory: `dist`
7. Deploy. Netlify will give you a public HTTPS URL you can add to LinkedIn.

### Option B — Vercel
1. Upload the project to GitHub.
2. Go to https://vercel.com/ and import the repository.
3. Vercel detects Vite. Use build command `npm run build` and output directory `dist` if prompted.
4. Deploy and copy the public URL.

## Important before publishing
- Your LinkedIn URL is already connected to the LinkedIn buttons.
- Contact email and phone are included; check they are correct before publishing.
- Experience details are summarized from information previously shared. Add exact employment dates, titles, and verified achievements if you want the journey section to be a formal employment timeline.
- Project descriptions are intentionally generalized. Only publish details you are authorized to share.
- This site does not currently include a CV download because a final CV file was not supplied.
